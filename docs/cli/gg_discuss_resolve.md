## gg discuss resolve

Close a discussion by linking it to a decision/task/rejection

```
gg discuss resolve DISC-ID [flags]
```

### Options

```
  -h, --help             help for resolve
      --summary string   short conclusion summary (e.g. 'decided X, see gg search')
      --via string       what concluded this: decision | task | rejection
```
