## gg status render

Generate STATUS.md from gg brain state

### Synopsis

Write STATUS.md to the project root, derived from live gg brain state.

  gg status render          # write STATUS.md
  gg status render --check  # exit non-zero if STATUS.md is stale (CI drift check)

The file begins with '<!-- GENERATED by gg status render. Do not edit. -->'
so any manual edit is visibly overwritten on the next run.

```
gg status render [flags]
```

### Options

```
      --check           exit non-zero if STATUS.md differs from what render would produce (CI drift check)
  -h, --help            help for render
      --output string   output file path (relative to project root) (default "STATUS.md")
```
