## gg note

Record a free-form activity note

### Synopsis

Stores a timestamped note in the activity log. Notes are embedded and
searchable via 'gg note search'. Use them to capture observations, progress
context, or anything that doesn't fit a decision, rejection, or task.

```
gg note "text" [flags]
```

### Options

```
  -h, --help          help for note
      --tags string   comma-separated tags
      --task string   link note to a task (e.g. TASK-042)
```
