## gg canon apply

Apply a filled canon op contract (add/edit/delete curated areas) — deterministic, offline

```
gg canon apply --ops <file|-> [flags]
```

### Options

```
      --dry-run      print the resolved ops without writing
  -h, --help         help for apply
      --ops string   path to a filled op contract JSON (or - for stdin)
```
