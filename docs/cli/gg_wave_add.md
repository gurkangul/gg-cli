## gg wave add

Create or update a wave node

```
gg wave add <wave-id> [flags]
```

### Options

```
      --end string      end date (YYYY-MM-DD)
      --goal string     sprint/milestone goal
  -h, --help            help for add
      --name string     wave display name
      --start string    start date (YYYY-MM-DD)
      --status string   wave status: active or closed (default "active")
```
