## gg init

Initialize shared gg infrastructure (~/.gg/) and register this project

```
gg init [flags]
```

### Options

```
  -h, --help               help for init
      --skip-enforcement   skip installing agent hooks and task-done gate scripts
```

### Options inherited from parent commands
