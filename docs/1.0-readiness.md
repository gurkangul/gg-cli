# 1.0 Readiness Audit

> Honest audit of where gg stood against the [Stability & Versioning Policy](./stability.md)
> on the road to 1.0. Every real blocker was either a filed follow-up task
> (TASK-id recorded inline) or an explicitly [deferred](#deferred-post-10) line.
> No silent omissions.
>
> **Update (1.0.0):** all blocking follow-ups below — TASK-493 (deprecation
> mechanism), TASK-494 (config/registry version stamp), TASK-495 (docs/cli
> drift), TASK-496 (experimental markers) — are **done**. The deferred items
> remain intentionally post-1.0. 1.0.0 was cut on this basis.

**Method.** The command surface was taken from the real binary, not source
heuristics: `go build -o /tmp/gg492 ./cmd/gg`, then `gg --help` plus
`gg <cmd> --help` for every top-level command (the exact commands exercised are
listed in [evidence](#evidence-ac-6)). Tier classification, hidden/deprecated
status, and storage findings are cross-checked against `cmd/*.go`,
`internal/store/`, `internal/config/`, and `internal/telemetry/`.

### Flagged items

- **Undocumented user-facing commands:** `onboard`, `serve` have **no** `docs/cli/`
  page. `docs/cli/` is auto-generated by `tools/docs-gen`, so this is **stale
  generated docs**, not a hand-written gap — regenerating produces both pages and
  also re-touches `gg.md`, `gg_doctor.md`, `gg_telemetry.md`,
  `gg_telemetry_compact-missed.md`. CI's drift check
  (`go run ./tools/docs-gen && git diff --exit-code docs/cli/`) is currently red.
  → **TASK-495** (filed; this task does **not** regenerate — out of scope).
- **Hidden but reachable:** `gg gsd-guard` runs even though it is not listed in
  `--help`. This is intentional (hook-only) and correctly classified internal —
  documented here so it is not a surprise at 1.0. No action needed beyond this note.
- **Experimental scaffolding with no runtime marker:** `audit`, `trace`, `metrics`,
  `telemetry`, `gsd`, `reconcile` are debug/observability/integration scaffolding,
  but their `--help` does **not** say "experimental", so a user can't tell them
  from frozen commands. → **TASK-496** (add `[experimental]` help markers; decide
  per-command graduate-vs-stay).

## Storage / format-version audit (AC-3)

Every persisted format and whether a 1.0 forward-compat guarantee is currently safe.

| Format | Location | Version / migration story | 1.0 forward-compat safe? |
|--------|----------|---------------------------|--------------------------|
| **Qdrant payloads** | `<project>-<suffix>` collections | No explicit per-payload schema version. Migration path exists for *dimension/model* changes via `ReembedAll` (`internal/store/reembed.go`), which is JSONL-authoritative and retry-safe. | **Mostly.** Field additions are tolerated (payloads are `map[string]any`); model/dim changes have a migration. No stamp to detect a future payload-shape break. See [deferred](#deferred-post-10). |
| **JSONL records** (decisions/tasks/bugs/messages/notes/discussions) | `.gg/brain/*.jsonl`, `.gg/*.jsonl` | Append-only, source-of-truth (BUG-069). New fields are additive; readers tolerate missing/unknown fields. No explicit record-level schema version. | **Yes** for additive evolution. A breaking field-semantics change would be unguarded. |
| **Memgraph nodes/edges** | Bolt graph (Decision/Task/Bug/Wave nodes, AFFECTS/link edges) | Rebuilt from Qdrant/JSONL via `reindex`/`backfill`/`reembed` commands — the graph is a **derived projection**, not a primary store. No node schema version. | **Yes** — derived, regenerable from authoritative JSONL/Qdrant; a schema change is handled by re-deriving, not migrating in place. |
| **`.gg/config.yaml`** | repo `.gg/` | **No `schema_version`.** Lenient `yaml.Unmarshal` (`internal/config/linked_projects.go`): unknown/removed keys silently ignored, `ApplyDefaults()` fills gaps. | **Read-safe** (older configs load), but removed keys are dropped **silently** (no warn) and there's no version stamp. → **TASK-494**. |
| **Sequence files** (`.task-seq`, `.bug-seq`, `.disc-seq`) | `.gg/` | Plain integer counters, file-locked. Corruption is detected with a clear "delete to re-bootstrap from qdrant" error; can re-bootstrap from Qdrant/JSONL. No version needed (trivial format). | **Yes** — stable trivial format with a self-healing bootstrap. |
| **`telemetry.jsonl`** (RendererV) | runtime dir | Carries `renderer_v` (`internal/telemetry/telemetry.go:63`) stamping the compact-renderer format version per record (per-verb versions in `cmd/compact.go`). | **Yes** — already format-versioned; the cleanest precedent in the codebase. |
| **`~/.gg/projects.json`** | host `~/.gg/` | `Registry{Projects map[...]}` (`internal/config/registry.go`) — **no version field.** Missing file = empty registry (first-use safe). | **Read-safe** today, but unversioned → unguarded against a future shape change. → **TASK-494**. |
| **`embedding-meta.json`** | `.gg/` | Records model name + vector dimension at collection-create time. On model change gg **fails fast** rather than writing incompatible vectors; `gg reembed --confirm` migrates (`docs/architecture.md` §Embedding model metadata). | **Yes** — explicit identity + fail-fast + migration command. |
| **Portable brain snapshot** | `.gg/brain/` + `manifest.json` | **Best-in-class:** explicit `schema_version: 1` (frozen) in `manifest.json`, checksums, embedding-identity guard, documented v1→v2 migration path (`docs/brain-export.md`). | **Yes** — the reference model for the whole policy. |

**Summary of gaps:** `config.yaml` and `projects.json` lack a version stamp and
silently drop removed keys (→ **TASK-494**). Qdrant payloads / JSONL records /
Memgraph nodes have no per-record schema version, but are protected in practice by
additive-field tolerance, JSONL-authoritative re-embed migration, and graph
re-derivation — a deeper per-payload stamp is [deferred](#deferred-post-10).
`telemetry.jsonl` and the brain snapshot already carry explicit format versions
and are the patterns to copy.

## Deprecation mechanism assessment (AC-5)

**Current state: there is NO standard deprecation mechanism.**

- No use of cobra's built-in `Deprecated:` command/flag field anywhere in `cmd/`
  (grep: zero `Deprecated:` matches).
- No shared warn helper. The only two deprecated commands each **hand-roll** their
  own one-off stderr warning:
  - `cmd/decide.go:42` — `warning: 'gg decide' is deprecated — use 'gg record' instead`
  - `cmd/reject.go:43` — `warning: 'gg reject' is deprecated — use 'gg record --decision-status=rejected' instead`
- The *shape* is already correct (warn to **stderr**, name the replacement, command
  still works), which validates the §4 policy — but it is duplicated, not reusable,
  and inconsistent in wording.

For 1.0, deprecations need one consistent, reusable mechanism so any future
deprecated command/flag behaves identically and is easy to add. → **TASK-493**
(add a shared deprecation-warning helper + adopt cobra `Deprecated`; do **not**
build it in this audit task).

## Gap punch-list (AC-4 + AC-5)

Every real 1.0 blocker found above was filed as a follow-up gg task — **all done before 1.0.0**:

| TASK | Title | Priority | Source AC | Status |
|------|-------|----------|-----------|--------|
| **TASK-493** | Add a shared CLI deprecation-warning helper + adopt cobra `Deprecated` | high | AC-5 | ✅ done |
| **TASK-494** | Stamp + warn-on-removed for `config.yaml` and `~/.gg/projects.json` | medium | AC-3 | ✅ done |
| **TASK-495** | Refresh stale `docs/cli` generated CLI reference (onboard, serve, drift) | medium | AC-2 | ✅ done |
| **TASK-496** | Mark experimental commands in `--help` so the stability tier is visible | low | AC-2 | ✅ done |

### Deferred post-1.0

- **Per-payload schema-version stamp on Qdrant payloads / JSONL records / Memgraph
  nodes.** *Rationale:* these are already protected in practice (additive-field
  tolerance, JSONL-authoritative `ReembedAll` migration for dim/model changes, and
  Memgraph re-derivation from the authoritative store). The portable brain snapshot
  already carries `schema_version` at the boundary where cross-version transfer
  actually happens. A pervasive per-record stamp is a larger refactor with low
  marginal safety before 1.0; revisit if a payload-shape break is ever needed.
- **Freezing/renaming/hiding any command.** *Rationale:* explicitly out of scope —
  this audit documents tiers; product decisions on graduating experimental commands
  to stable (or hiding them) ride on TASK-496 and per-command owner calls.
